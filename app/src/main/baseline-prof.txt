# S2: baseline profile for HushCast (human-readable ART profile rules).
#
# Installed by androidx.profileinstaller and compiled ahead of time on install, so the code below
# doesn't start out interpreted.  Rules use wildcards on purpose: the app is Compose-heavy, and
# most of the hot code is in generated lambda classes (Foo**) whose names change between builds.
#
#   H = hot, S = run during startup, P = run after startup.
#   HSPL<class>;->**(**)**   every method of that class
#   HSPL<class>**->**(**)**  the class and its lambda/inner classes
#   L<package>/**;           preload every class in the package
#
# Extend with a generated profile (Macrobenchmark BaselineProfileRule) when there's a
# benchmark module; generated rules can be appended below these.
